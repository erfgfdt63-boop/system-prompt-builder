What’s the difference between ChatGPT custom instructions and a system prompt?

They are the same kind of text: a standing “who you are / how to answer” block that shapes every reply. ChatGPT stores it under Settings → Custom Instructions (or a Custom GPT’s instructions). Claude and many bots call the same block a system prompt or Project instructions. This tool writes that block once so you can paste it anywhere.

Where do I paste the output in ChatGPT?

Settings → Personalization → Custom Instructions (on mobile: Settings → Customize ChatGPT). You can also paste it into a Custom GPT’s instructions field.

Can I use this as a Claude project instructions builder?
